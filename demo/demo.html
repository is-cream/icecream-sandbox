icecream-sandbox demo

Guest code runs inside QuickJS (WebAssembly) in a Web Worker inside a sandboxed iframe. It can only reach the host through host.send, host.ask, and the gated host.fetchText (the host fetches only after you approve). Try the buttons, or edit the code — an infinite loop stops at the deadline instead of hanging the page.

Gated connections

The guest has no network. It can only ask the host to fetch, and the host asks you first (this demo uses confirm; a real app shows its own approval UI). OK grants the origin for this session; Cancel denies.

Guest app rendering

The counter below is guest code: it fetches a stylesheet through the gate, then sends an element tree that the host renders inside a shadow root. Clicking +1 round-trips back to the guest, which re-renders. (The app holds the run while it lives; stop it before running other code.)
