Guest app with a real npm import

This app is not host code. It is a guest ES module running inside QuickJS in a Web Worker inside a sandboxed iframe (icecream-sandbox). Its first line is import { format } from 'd3-format' — a real published package, not a stub. There is no install step: the host's import map points that specifier at a URL, and the sandbox downloads it through the same connection gate as any guest fetch.

On the first run the host asks you to approve the download origin (one approval). Approve, and the module downloads and runs. Press Re-run and the same import comes from the host-side cache: no new prompt, no new download. Change the number or pick a format and the guest re-renders using the imported format function.

The vendored module is the byte-identical published d3-format 3.1.2 ESM bundle (see examples/vendor/NOTICE.md). In production an app would point its import map at a CDN instead; the download mechanism — gate approval, then caching — is identical either way.
