Static import + dynamic import

One guest app, two real chart libraries, two import styles. The app is a module running inside QuickJS in a Web Worker inside a sandboxed iframe (icecream-sandbox).

  • Static: the first line is import { Chart } from 'chart.js' — Chart.js 4.6.1 downloads with the import graph (including its own dependency, @kurkle/color) and is ready before anything runs.
  • Dynamic: press Load Chartist and the guest imports Chartist 1.3.1 by name, at that moment — the host approves the origin, the module downloads, and the guest re-renders with it.

Both downloads go through the same connection gate and the same host-side cache: approve an origin once and later loads are silent. The app decides which packages exist via the import map — the guest only picks among them, whether by literal import or by name.
