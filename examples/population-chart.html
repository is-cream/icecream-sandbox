World population, 1920 to now

This chart is not host code. It is a guest component: JavaScript running inside QuickJS in a Web Worker inside a sandboxed iframe (browser-sandbox). The guest describes its UI as data; the host renders it inside a shadow root. The guest cannot touch this page's DOM, cannot fetch anything itself, and cannot navigate anywhere on its own.

Click a bar to see that decade's detail. Switch views between total population and growth per decade. Click a source link and the host asks you first — the click never navigates on its own, because the link carries an event id and the renderer prevent-defaults gated links. Approve, and the host opens it; deny, and nothing happens.
